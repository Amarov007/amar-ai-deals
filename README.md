# Amaro AI Discover

Act as a Principal Full-Stack Web Architect and Senior UI/UX Designer specializing in top-tier AI applications. Design and structure a production-ready, modern AI Discovery and Deals Platform named "AMAR007AI".

Incorporate the exact specifications, features, visual styling, and multilingual architecture detailed below:

### 1. Branding & Visual Identity (Gemini-Inspired Aesthetic)

- Platform Name: "AMAR007AI" (Display with a glowing multi-color gradient typography and an AI core emblem).

- Dark Mode by Default: Deep space midnight background (#0B0F19 and #030712).

- Dynamic Glowing Gradients: Authentic Gemini-style color flows combining Electric Cyan (#38BDF8), Deep Blue (#2563EB), Neon Violet/Purple (#8B5CF6), and subtle Magenta Glow (#EC4899).

- Glassmorphism & Micro-Interactions: Translucent cards with backdrop blur, fine glowing borders (1px translucent edges), subtle pulsing gradient mesh backgrounds, and smooth hover lift animations.

### 2. Multilingual Support (i18n) & Language Switcher

- Dedicated Language Switcher: Placed prominently in the sticky header with support for 3 languages:

  1. English (EN - Default)

  2. العربية (AR - Full RTL layout direction support)

  3. Русский (RU)

- Localized UI Elements: Seamless dynamic translation for all navigation items, category names, badges, filters, search placeholders, deal timers, and modal dialogs.

- Detailed Tool Dossiers: Tool descriptions, pros/cons, and key feature breakdowns must be fully localized or cleanly adapted for all three languages.

### 3. Comprehensive Tool Specifications (Official Logos & Direct Links)

- Every indexed AI tool entry must feature:

  * Official High-Resolution Brand Logo / SVG Icon.

  * Verified Official Website Link (direct outbound CTA button: "Launch Tool" / "Claim Offer").

  * Pricing Status Badges: "100% Free", "Freemium", "Open Source", or "Limited Free Deal / Voucher".

  * Punchy Tagline & In-Depth Technical Description.

  * Bulleted Key Features & Primary Use-Cases.

  * Last Synced / Updated Timestamp (e.g., "Updated 10 mins ago").

### 4. Layout Architecture & Key Functional Sections

- Sticky Glass Header:

  * AMAR007AI Glowing Logo.

  * Real-time global search bar with instant predictive autocomplete.

  * Multilingual Switcher dropdown (EN / AR / RU).

  * System status pill: "Server Auto-Sync: Active" & "Live Deals Tracker".

- Hero Section:

  * High-impact bilingual/trilingual headline highlighting zero-cost AI models and exclusive limited-time trial vouchers.

  * Category quick-filter pills (LLMs, Image & Design, Video/Audio, Code Intelligence, Automation & Productivity).

  * Real-time metrics counters (Total Indexed Free Tools, Active Promo Coupons, Daily Updates).

- Filterable Main Tools Grid:

  * Responsive multi-column layout with instant client-side filtering and multi-criteria sorting (Newest, Highest Rated, Ending Soon).

- Dedicated Limited-Time Deals Hub:

  * Spotlight section for paid AI services currently offering 100% free trials, promo codes, or free API credits.

  * Integrated real-time countdown timers and one-click coupon copy buttons.

- Interactive Tool Modal / Side Drawer:

  * Clicking any card triggers an expanded dossier showing official documentation links, API availability status, release notes, and coupon redemption steps.

### 5. Automated Server Sync & Update Engine

- Scheduled Serverless Cron Jobs (hourly execution) connecting to developer APIs, RSS feeds, and changelogs to index new tools and product releases automatically.

- AI-Powered Summarizer pipeline that generates structured descriptions, categorizes tools, and tags features automatically.

- Smart Expiration Monitor to automatically expire coupons and downgrade deal badges in real time once promotional periods end.

Deliver the complete structural layout, page flow, and technical specifications meeting all the criteria above.
